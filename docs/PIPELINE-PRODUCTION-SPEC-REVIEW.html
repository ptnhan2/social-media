3 · Chìa khóa: per-field override ledger giải quyết parity tự động

1️⃣ Bạn sửa

Sửa providerText clip VO beat-2 trong Audio tab

2️⃣ Ledger ghi

Field providerText đánh dấu overridden (machinery hardening đợt 3 — đã build)

3️⃣ Agent regen

Lần sau agent chạy lại direction cho cả video: clip beat-2 GIỮ text bạn sửa (hoặc flag stale nếu structure đổi)

4️⃣ Học gu

Diff agent-version → human-version vào feedback.jsonl = nguyên liệu học gu tốt nhất

Không state song song, không cơ chế locking mới — một doc editor/current.json, revision + 409 + per-field override + migrations: tất cả đã chạy cho video clips, giờ dùng cho voice + image metadata.
