Production Pipeline Spec v2

5 production pipelines + Agent-Human Parity trên mọi stage. DRAFT v2 — chờ duyệt2026-08-27 tối · AGENTS.md rule #16

Đối chiếu rule cốt lõi của bạn (giờ là AGENTS.md #16): "Agent làm được thì human cũng làm được — xem + sửa được, không hộp đen."

Audit v1: 15/15 stage là hộp đen. Agent chạy mọi thứ, user chỉ thấy approve/reject 1 bit. v2 viết lại: mỗi stage khai báo human surface, parity ship CÙNG stage (không bolt-on sau), và mọi lần user SỬA = feedback signal đầy đủ cho learning loop — mạnh hơn approve/reject.

2 · Voice pipeline — 10 stages, mỗi stage có human surface

A plan→ B direction→ C sample→ D generate→ E QC→ F select→ G post→ H timing→ I mix-plan→ J record
StageAgent làm gìBạn xem + sửa được gìGate
A plan Script → câu, batch theo BEAT (fix bug batch-tùy-ý) Direction panel: beat ↔ câu; sửa text, tách/gộp batch → revision bump, agent đọc lại mọi beat ≥1 batch
B direction Sinh cues + providerText — chuỗi THẬT gửi ElevenLabs (tags/CAPS/breaks). Fix bug "directive không được áp". Quy tắc: không đổi từ, chỉ thêm tags Provider text field — như prompt Asset Studio: thấy đúng chuỗi sẽ gửi, sửa trực tiếp ([pause], CAPS). Mọi edit = feedback diff review cues 1 lần
C sample Gen 1 take từ batch khó nhất + QC Sample player + SỬA direction rồi re-sample — không chỉ approve/reject approve ≤3 iter
D generate Multi-take 2-3/batch, identical settings mọi call, with-timestamps → word timing Voice settings panel: voiceId, stability, style, speed — chỉnh được (edit = feedback gu giọng) settings so programmatic
E QC WER ≤5% (whisperx so script), clip ≥−0.5dB FAIL, duration ±15%, silence >1.5s QC dashboard per take: badge PASS/FAIL + số + audio player + transcript diff highlight (từ sai chỗ nào) fail → loại/regen
F select Best-take scoring (dynamic − timing − clip penalty) Takes list: play từng take, ĐỔI take được — override là feedback mạnh nhất về gu auto + override
G post HPF 80Hz → denoise → EQ → comp 3:1 → 2-pass loudnorm −16 LUFS / −1.5 TP. VO giữ KHÔ; room = ambience + ducking (DuckZones render đã có) Chain params = style-store knobs (như fonts); A/B preview trước/sau từng take loudnorm 2-pass
H timing Stem durations → beat durationSec = stem + breath pad; VO >×1.05 planned → flag rewrite Timing diff view: beat trước → sau + waveform overlay; chỉnh padding từng beat trước khi apply patch + verify
I mix-plan Emit AudioPlan: stems, music duck 18-20dB + cut 2-4kHz, SFX, master −16/−1.5 Audio inspector (gain/mute per track đã có trong Composer) schema validate
J record Ghi KB + preferences Mọi human-edit diff (B/C/D/F/H) cũng vào feedback.jsonl —

3 · Image sourcing — query cards như prompt Asset Studio

🖼 Agent stages

  • Query build per beat + CHAI 3-pass self-review
  • Unsplash fetch (Pexels fallback) · perceptual-hash dedupe mọi video
  • Provenance: photographer + license + URL
  • Cohesion grade từ style store · VLM relevance QC (grounded, AUTO được)

👤 Human surface

  • Query card per beat — sửa query, bấm re-search (như prompt Asset Studio)
  • Candidate grid: provenance badge + QC verdict mỗi ảnh
  • Đổi ảnh: chọn candidate khác hoặc upload ảnh own (upload API có sẵn)
  • Grade knob chỉnh toàn video · taste keep SAU khi đã chỉnh mọi thứ

4 · Timeline / validate / scaffold

  • generate_timeline: generation report hiện trong Composer (warnings, missing assets) — không nuốt trong stdout; user thấy, tự fix edit-doc qua editor, regenerate
  • validate_edit_doc: checklist PASS/FAIL render trong panel — cùng report agent đọc
  • new_project: project list + create đã có sẵn UI

5 · Learning loop nâng cấp — edits là tín hiệu đầy đủ

Trước (v1)

Approve/reject = 1 bit mỗi gate. Học được ít.

Sau (v2)

Human EDIT = demonstration đầy đủ. Diff agent-version → human-version ghi feedback.jsonl với knob cụ thể.

Ví dụ

Bạn sửa providerText batch-3 thêm [pause] → principle candidate: "user muốn nghỉ ở mệnh đề phụ". Bạn đổi take 2→1 → "user ưu tiên giọng trầm hơn".

pattern_extractor

Mở rộng nhóm edit-patterns → principle candidates. Ưu tiên học từ edit hơn verdict.
