2 · Voice pipeline — 10 stages, VO là đồng hồ

A plan→ B direction→ C sample gate→ D generate→ E QC→ F select→ G post→ H timing→ I mix-plan→ J record
StageNội dung — đối chiếu 4 điểm bạn nêuGate
A plan Batch theo BEAT (fix bug batch-tùy-ý) — mọi beat có voice riêng, regen surgical được mọi beat có ≥1 batch
B direction Nhấn nhá (điểm 1): voice_performance plan + per-batch delivery cues → provider text prep. multilingual_v2: CAPS + punctuation + pronunciation dictionary (≤3 locators). eleven_v3: audio tags [pause] [excited] + IPA (80-90%). Quy tắc sắt: không đổi từ, chỉ thêm tags/caps — và fix bug "directive không được áp" human review cues 1 lần
C sample gate Generate 1 take từ batch khó nhất (không phải batch đầu) — duyệt trước khi batch. Flat-voice → sửa direction, không batch human approve ≤3 iter (~$0.05 chống waste $1-3)
D generate Loại giọng (điểm 2): voice identity của kênh, multi-take 2-3/batch, identical settings mọi call (voice consistency enforcement), endpoint with-timestamps → char-level alignment = word timing miễn phí settings so programmatic
E qc Deterministic (VLM mù tiếng): WER ≤ 5% (whisperx transcribe so script; tên riêng 0 sai), clip max_volume ≥ -0.5dB FAIL, duration ±15%, silence >1.5s flag, confidence <0.8 flag take fail → loại; batch fail → regen
F select Best-take scoring có sẵn (dynamic range − timing penalty − clip penalty), lọc theo QC pass; target từ alignment thực auto
G post Âm vang / tiếng phòng (điểm 3+4): VO TTS giữ KHÔ (reverb trực tiếp = muddiness — sound-design rule). Room feel = ambience bed + ducking (render đã hỗ trợ DuckZones). Chain: HPF 80Hz → denoise → EQ cut 500Hz / boost 3kHz / notch 6-8k artifact → comp 3:1 → 2-pass loudnorm −16 LUFS · TP −1.5 · linear=true. Scene bigSpace mới thêm room send nhẹ (knob, default OFF) loudnorm 2-pass
H timing Voice-first coupling: measured stem duration → beat durationSec = stem + breath pad 0.25-0.4s, áp qua editor_op/patch (không hand-edit). VO > planned ×1.05 → flag rewrite script patch + verify
I mix-plan Emit AudioPlan có sẵn: stems + offsets, music beds (duck 18-20dB, cut 2-4kHz music band), SFX cues (whoosh lead 10-20ms), master {−16 LUFS, −1.5 TP, limiter} schema validate
J record Voice identity + settings thắng + QC scores + human verdict → memory (KB + preferences) — agent học giọng, không đoán lại —

3 · Bốn pipeline còn lại — cùng kiểu stages + gates

🖼 source_image — 7 stages

  • Query build per beat (script semantics + mood) + CHAI 3-pass self-review
  • Fetch Unsplash (Pexels fallback) → dedupe perceptual-hash (không tái dùng ảnh cũ)
  • Provenance bắt buộc: photographer + license + URL
  • Cohesion: một hệ grade từ style store (không dán cover mỗi ảnh một kiểu)
  • Relevance QC: VLM AUTO được (grounded presence check — điểm mạnh của VLM) → fail → query lại ≤2 vòng → human taste keep

🎬 generate_timeline + validate + scaffold

  • generate_timeline: wrap generate-editor cold + bắt buộc qua validate trước; output structured JSON (warnings, missing assets) — agent tự chẩn đoán, không nuốt warning
  • validate_edit_doc: contiguity, duration >0, assets tồn tại trên disk, audio cues resolvable, params đủ, schemaVersion
  • new_project: contract chuẩn (00-state, 7 dirs, schemaVersion, slug regex)

4 · Ranh giới vai trò (chốt từ trưa nay)

🤖 Agent

Chạy TOÀN BỘ stages, đọc QC numbers, tự quyết bước tiếp trong budget (≤40 calls tiered)

👤 Bạn

Xuất hiện tại đúng 3 gates: sample approval (voice), image taste, final keep. Mỗi gate = 1 quyết định, không QA tay

🔧 Builder (Kilo)

Chỉ thêm capability/surface mới. Không chạy stage thay agent — kể cả nhanh hơn

🧠 Memory

Mọi human verdict + settings thắng + QC numbers ghi vào KB/preferences — flywheel học gu
