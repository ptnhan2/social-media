# Content Calendar — 30 Day Plan (v2 — 3 pillar)

> 3 pillar: (1) AI tool review, (2) daily build-in-public, (3) writing craft analysis.
> Tất cả automatable. Bạn chỉ review/fix. ~2h/tuần.

---

## Daily (automated, ~1 min/day)

**Build-in-public devlog** — agent đọc git log → sinh post (social-post F1):
- Platform: X + Threads
- Format: "Day [N]: [what I built/fixed/decided today]"
- Example: "Day 15: AI agent learned to maintain character voice across chapters. Bug: it forgot the villain's motivation after 3k words. Fix: added story-state tracking."
- Automation: git log → agent → draft → bạn approve → publish thủ công
- **You: 1 min approve**

---

## Weekly (review/fix, ~30 min/tuần)

### Tool review (biweekly, pillar 1)
**Week 1**: Review [Tool A] (vd Sudowrite)
- Agent: research Sudowrite docs + web → draft review (features, pros/cons, pricing, use case for novelists)
- You: test tool 10min + fix draft 15min
- Format: YouTube 10-15min (screen recording + Open Design motion overlay) OR blog post
- Title: "Sudowrite Review: Is It Actually Good for Writing Novels?"
- Repurpose: Short (tool demo highlight) + X thread + Newsletter section

**Week 3**: Review [Tool B] (vd NovelCrafter)
- Same flow
- Title: "NovelCrafter vs Sudowrite: Which AI Writing Tool Wins for Novelists?"

### Craft analysis (biweekly, pillar 3)
**Week 2**: Analyze [novel/franchise]
- Agent: research [novel] plot/characters/reviews → analyze (character arc / plot structure / worldbuilding)
- You: fix craft accuracy 15-30min
- Format: YouTube 15-30min video essay (Open Design, HFM-style analytical)
- Title: "Why [Mistborn]'s Magic System Works (And How AI Can Learn From It)"
- Repurpose: Shorts (key insight) + X thread + Blog + Reddit

**Week 4**: Analyze [writing technique]
- Agent: research technique (vd "Promise/Progress/Payoff" from Sanderson) → explain + examples from popular novels
- You: fix accuracy 15min
- Title: "The Promise/Progress/Payoff Framework — Explained for AI-Assisted Writing"

### Newsletter (weekly Friday)
- Agent: compile week's devlog + content + product progress → draft newsletter
- You: fix 10min → publish (Substack/Beehiiv)
- CTA: product waitlist + "reply with your biggest AI-writing struggle"
