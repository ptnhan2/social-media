# Script: The Timeline Is Not The Edit

The polished timeline can still hide the real problem.

A cut is not a gap between clips. It is a decision.

The screen is useful only when it proves the decision.

Start with the story, then place the voice, evidence, and cut.

Two edits can use the same tools and still tell different stories.

When every frame tries to impress, the viewer cannot see what changed.

Make the next frame answer the question raised by the last one.

Choose the decision first. Then let the frame move.
