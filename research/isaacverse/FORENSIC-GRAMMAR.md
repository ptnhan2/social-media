### A. One coherent host/world system
- Black or near-black presentation field.
- Recurring amber/gold line-art Isaac world with practical lights, rooms, desks, monitors and character close-ups.
- Isaac character appears as line-art, illustration, cutout, live-action composite or host avatar depending on the narrative beat.
- Small italic warm-yellow subtitle system in cinematic/letterboxed shots.
- The visual identity is not a static palette: amber is the continuity anchor, while cyan/green/red accents appear when the semantic role calls for contrast.

- YouTube comments → isolated black card → layered/tilted montage → monitor prop → line-art scene.
- Dashboard/analytics → readable metric proof → graph highlight → host reaction/argument.
- Premiere workspace → screen recording + Isaac character + timeline context.
- Thumbnail/channel page → browse-scale proof → zoomed inspection → diagram or comparison.
- Prompt/UI/tool output → staged interface + host → candidate comparison → failure/success beat.
